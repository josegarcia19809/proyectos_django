book_set es el nombre que Django crea automáticamente para acceder a todos los objetos relacionados desde el otro lado de una relación ForeignKey.

En tus modelos:

class Author(models.Model):
    first_name = models.CharField(max_length=100)
    last_name = models.CharField(max_length=100)

class Book(models.Model):
    title = models.CharField(max_length=100)
    author = models.ForeignKey(Author, on_delete=models.CASCADE)

La relación es:

Un Author puede tener muchos Book.
Un Book pertenece a un Author.

Como Book tiene una clave foránea hacia Author, Django agrega automáticamente el atributo book_set al modelo Author.

Ejemplo

Supongamos que tienes este autor:

author = Author.objects.get(last_name="García")

Para obtener todos sus libros:

books = author.book_set.all()

for book in books:
    print(book.title)

Salida:

Cien años de soledad
El coronel no tiene quien le escriba
¿Por qué se llama book_set?

Django sigue la convención:

nombre_del_modelo_en_minúsculas + _set

Por ejemplo:

Modelo	Nombre generado
Book	book_set
Movie	movie_set
Student	student_set
¿Qué métodos tiene book_set?

Como book_set es un Manager, puedes hacer casi cualquier consulta del ORM:

# Todos los libros
author.book_set.all()

# Filtrar
author.book_set.filter(rating=5)

# Contar
author.book_set.count()

# Obtener uno
author.book_set.get(id=1)

# Ordenar
author.book_set.order_by("title")
¿Se puede cambiar el nombre?

Sí. Lo recomendable es usar related_name.

class Book(models.Model):
    title = models.CharField(max_length=100)
    author = models.ForeignKey(
        Author,
        on_delete=models.CASCADE,
        related_name="books"
    )

Ahora, en lugar de:

author.book_set.all()

puedes escribir:

author.books.all()

que resulta más natural y legible.

Resumen
book_set es un manager que Django crea automáticamente para acceder a los libros de un autor.
Solo existe porque Book tiene un ForeignKey hacia Author.
Permite realizar consultas como .all(), .filter(), .count(), etc.
Es una buena práctica reemplazar book_set por un nombre más descriptivo usando related_name, por ejemplo books.

>>> from book_outlet.models import Book, Author
>>> gabriel = Author.objects.get(first_name="Gabriel")
>>> gabriel.books.all()

>>> gabriel.books.filter(rating__gt=3)
